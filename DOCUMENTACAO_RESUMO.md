## 💡 Dicas Importantes

### 1. Comece pelo ColorScheme
Crie `ColorScheme.java` PRIMEIRO, pois todos os outros componentes dependem dele.

### 2. Use GridBagLayout para Formulários
Para layouts complexos e formulários, use `GridBagLayout` ao invés de `BorderLayout`.

### 3. Rounded Corners em Swing
Sempre use `Graphics2D` com `RenderingHints.KEY_ANTIALIASING` para linhas suaves.

### 4. Fonte Fallback
FontManager.java já cuida disso, detectando Inter → Segoe UI → Dialog automaticamente.

### 5. API Communication
Use `ApiClient.java` que já implementa tratamento de erros e serialização com GSON.

## 🐛 Problemas Comuns

| Problema | Solução |
|----------|---------|
| Fontes estranhas | Use FontManager.java (fallback automático) |
| Cores diferentes | Copie exatamente de ColorScheme.java |
| Components distorcidos | Use setOpaque(false) em painéis customizados |
| Layout desalinhado | Use GridBagLayout com GridBagConstraints |
| API não conecta | Verifique URL (localhost:8080) e status do backend |
